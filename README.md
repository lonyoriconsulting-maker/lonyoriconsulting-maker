# LERO Systems

**Founder & Lead Developer | LERO Systems, Arusha, Tanzania | Swahili & Offline-First SME Systems**

I build software and data systems for East African businesses: Swahili-first, offline-first, and fitted to how SMEs actually run.

## Product pillars
- **LERO Biashara** - Swahili WhatsApp tools, mobile-money reconciliation, TRA-ready reports
- **LERO Fleet** - fuel-siphoning detection and driver risk scoring
- **LERO Hospitality** - guest house ops audits, SOPs, 90-day occupancy packages
- **LERO Academy** - training programs (in development)
